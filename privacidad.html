Política de privacidad

Última actualización: 23 de octubre de 2026.

Qué datos usa la app

Con permiso del usuario, Espacio de Diego Loki accede a metadatos de su cuenta de Google: en Gmail, remitente, asunto, fecha y etiquetas (ámbito gmail.metadata); en Drive, nombre, tipo, fecha de modificación y enlace de los archivos (ámbito drive.metadata.readonly). Nunca lee el cuerpo de los correos ni el contenido de los archivos, y no puede enviar, modificar ni borrar nada.

Dónde se guardan

Los datos se guardan solo en el ordenador del usuario, en una base de datos local. El permiso de acceso se guarda cifrado con la protección de Windows. No hay servidores propios ni se envían datos a terceros.

Uso y compartición

Los datos se usan únicamente para mostrar al usuario sus propios avisos y pendientes. No se venden, no se comparten y no se usan para publicidad ni para entrenar modelos de inteligencia artificial.

Cómo retirar el acceso

El usuario puede desconectar una cuenta desde la propia app, que borra el permiso local, o revocar el acceso en myaccount.google.com/permissions.

Cumplimiento

El uso de la información recibida de las API de Google se ajusta a la Política de datos de usuario de los servicios de API de Google, incluidos los requisitos de uso limitado.
